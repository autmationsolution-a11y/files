▸ Ce dont j'ai besoin pour démarrer

Les cinq choses qui débloquent la construction

  • Un fichier exemple anonymisé un export Campbell .dat, 1 à 2 semaines, envoyé en privé (jamais public)
  • Liste capteurs / profondeurs / variables ce qui est mesuré, à quelles profondeurs, noms exacts des colonnes
  • Unités + limites physiques par variable, plus des min/max réalistes pour les contrôles de plausibilité
  • La machine sur laquelle ça tourne l'OS, et la possibilité d'installer Python 3.10+
  • Modèle local confirmé pour garder les données sur place, l'IA tourne en local, pas dans le cloud
▸ Comment c'est construit

Réutilise un cerveau déjà fonctionnel

Le cœur de raisonnement (LLM local, appel d'outils, recherche) est un moteur existant et testé. On ne construit que la couche données, donc la mise en route est rapide.

Gouvernance par conception

Les données restent sur la machine CNRS. Le texte sensible passe par Emmy. Chaque règle de contrôle qualité est versionnée et reproductible.
