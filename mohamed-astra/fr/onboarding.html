ASTRA // MOHAMED

Demande d'onboarding

Les informations qui permettent de lancer Astra. La plupart sont rapides. La seule donnée nécessaire est un petit échantillon anonymisé, partagé en privé.

Aucune donnée sur GitHub. Les vraies données de l'observatoire ne sont jamais téléversées ici. Partage le fichier exemple uniquement par un canal privé.

A Données

A1. Fichier exemple un export Campbell .dat / TOA5, 1 à 2 semaines, avec les lignes d'en-tête. Privé, non versionné.
A2. Inventaire des capteurs liste des instruments.
A3. Profondeurs ex. 10, 30, 50, 100 cm.
A4. Variables chaque variable avec son nom de colonne exact.
A5. Unités par variable. Potentiel matriciel : kPa / hPa / pF.
A6. Sites / stations identifiants des stations.
A7. Fréquence + fuseau horaire pas d'échantillonnage et fuseau des horodatages.
A8. Limites physiques min/max stricts par variable (pour les contrôles de Niveau 1).
A9. Drapeaux existants toute convention de drapeau qualité déjà en place.

B Environnement

B1. Machine + OS la machine qui fait tourner Astra.
B2. Python 3.10+ et la permission d'installer duckdb / pandas / pyarrow.
B3. Où ça tourne machine CNRS, ou machine de Younes sur un échantillon copié.
B4. Emplacement des données où les fichiers se trouvent sur le disque.

C Cerveau

C1. Modèle local la gouvernance l'exige probablement. À confirmer.
C2. Moteur local Ollama / llama.cpp / LM Studio / vLLM / MLX.
C3. Matériel GPU + VRAM, ou CPU + RAM. Détermine la taille du modèle.
C4. Emmy (optionnel) Mistral/Emmy pour texte non sensible uniquement, si autorisé.
C5. Modèle par défaut identifiant du modèle préféré.

D Interface

D1. Hébergement du HUD à 127.0.0.1:8000, ou un autre hôte.
D2. Voix activée / désactivée (désactivée recommandée pour la v1).
D3. Langue FR / EN / bilingue.

E Dépôt & gouvernance

E1. Hôte GitHub, ou miroir vers un GitLab / forge CNRS.
E2. Propriétaire / admin
E3. Frontière des données confirmer que les données ne quittent jamais la machine (supposé oui).
E4. Exigences FAIR, reproductibilité, licence.

F Rôles

F1. Propriétaire des données
F2. Validation des seuils qui valide les limites de Niveau 1 et les seuils qualité.
F3. Droits de décision Mohamed vs Younes.
F4. Utilisateur du jour 1
Seuil de démarrage : une fois A1-A8, B1-B3 et C1-C3 renseignés, Astra peut démarrer. Le reste peut suivre.
