▸ What we need from you to go live

The five things that unblock the build

  • One sanitized sample file a Campbell .dat export, 1-2 weeks, shared privately (never public)
  • Sensor / depth / variable list what is measured, at which depths, exact column names
  • Units + physical limits per variable, plus realistic min/max for plausibility checks
  • The machine it runs on OS, and that Python 3.10+ can be installed
  • Local model confirmed to keep data on-prem, the AI runs locally, not in the cloud
▸ How it is built

Reuses a brain that already works

The reasoning core (local LLM, tool-calling, retrieval) is an existing, tested engine. We build only the data layer on top, so go-live is fast.

Governance by design

Data stays on the CNRS machine. Sensitive text goes through Emmy. Every quality-control rule is version-controlled and reproducible.
